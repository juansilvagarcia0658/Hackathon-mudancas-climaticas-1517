# 🌍 EcoHábitos (Insira o Nome do Seu Projeto)

Este é o meu projeto final de curso. O objetivo principal do site é ajudar qualquer pessoa a entender como as suas ações do dia a dia afetam o clima do planeta. Você pode preencher um formulário rápido para descobrir a quantidade de carbono que você produz. Depois disso, o site mostra um resultado na hora e deixa você anotar os seus hábitos todos os dias para ver a sua melhora com o tempo.

## 🚀 Funcionalidades

* **Calculadora de Carbono:** Um formulário simples para preencher dados sobre transporte, energia e alimentação.
* **Resultados Dinâmicos:** Um painel que mostra a sua pegada de carbono logo após o preenchimento.
* **Diário de Hábitos:** Uma área para registrar as boas ações do dia (como usar ecobag, andar a pé ou reciclar o lixo).
* **Progresso Visual:** Acompanhamento de como os seus novos hábitos estão diminuindo a sua pegada de carbono ao longo das semanas.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído juntando vários conhecimentos adquiridos no curso:

* **Backend:** Python com Flask.
* **Frontend:** HTML, CSS .
* **Banco de Dados:** SQLite (ou outro de sua escolha) para salvar os hábitos dos usuários.
